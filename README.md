# admissible-boundary-control
Concept disclosure for boundary-normal safety control.

Title:
Admissible Boundary Folding Control Framework

Core Safety Function:
Fold the trajectory of ε(t) inside Γ_c
by enforcing u(t) < 0

Definitions:
ε(t): measurable hazard deviation trajectory
Γ_c: decision boundary of admissible domain
u(t): controllable component along the boundary normal

Claim:
System safety is ensured by controlling only the normal component
of the critical boundary, independent of full-state regulation.

Status:
Concept disclosure / prior art fixation.
